# Online Food Delivery Analysis

## Project Overview
This project analyzes online food delivery data to understand order patterns, customer behavior, revenue, delivery performance, and order cancellations.

## Objectives
- Analyze order and revenue trends.
- Identify weekday and weekend ordering patterns.
- Explore city-wise and cuisine-wise performance.
- Examine delivery time and distance.
- Understand order cancellations and their reasons.

## Tools & Technologies
- Python
- Pandas
- MySQL
- Power BI
- coolab Notebook

## Key Insights
- Total orders analyzed: 100,000.
- Delivered orders: 84,964.
- Cancelled orders: 15,036.
- Cancellation rate: 15.04%.
- Distance and delivery time showed almost no linear correlation in this dataset (correlation: 0.003).
- Late Delivery was the most frequently recorded cancellation reason.

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL-based analysis
5. Data visualization and dashboarding
6. Insights and reporting

## Project Files
This repository contains the project notebook, SQL analysis, datasets, visualizations, and documentation.

## Conclusion
The analysis provides insights into order trends, customer spending, delivery performance, and cancellation patterns that can support data-driven decisions in food delivery operations.
